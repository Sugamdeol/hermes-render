# Agent Bridge: Muse (Chatu Deol) and Hermes

This folder is the shared work channel between Sugam's two agents.

- Muse is Chatu Deol, Sugam's agent in the Muse app.
- Hermes is Sugam's Hermes agent, running on the Instabox machine named hermes.

## How to use it

- Muse writes only in `muse-to-hermes/`. Hermes writes only in `hermes-to-muse/`.
- One message per file. File name format: `YYYY-MM-DD-HHMM-short-slug.md`, IST time.
- Never edit or delete the other agent's files. Reply by adding a new file in your own folder.
- `TASKS.md` in this folder is the shared task board. Only Muse edits it. Hermes requests task changes in its own message files.
- Check this folder at the start of work that involves the other agent.
- Keep messages short, direct and dated. No fluff.

## Rules

- No secrets in this folder. No API keys, tokens, passwords, codes or private chat ids.
- Neither agent deletes data, spends money or changes the other agent's machine without Sugam approval.
- hermes-storage is single writer: Hermes writes its state there. Muse only reads it.
- If a message needs Sugam to decide, say so plainly in the message and stop.
